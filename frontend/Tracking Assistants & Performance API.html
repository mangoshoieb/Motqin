For the front
  • Show the Arabic message for error.code. error.message is English text for developers; never show it. For a code missing from the list, show a general "something went wrong".
  • validation_error: details keys use the server's spelling, e.g. {"PhoneNumber": ["The PhoneNumber field is required."]}. Match them to your fields ignoring case and show each under its field.
  • Times are UTC but have no Z. Add it before converting to local time: 
    // Dart

// JS
new Date(s.endsWith('Z') ? s : s + 'Z');

Performance report
POST/api/tracking-tables/{groupId}/performancenewteacher or assistant

How the students did across the exams the teacher picks. Send 1 to 20 Exam column ids, oldest first. rowIds: null means every student. It reads only.

The statistics, explained simply

  • Everything is a percent of the full mark, so a 15/20 and a 30/40 are both 75. Numbers come rounded to 1 decimal: add % and don't round again.
  • Absent ("غائب") and empty cells don't count in any average; they're counted on their own.
  • "Average" is a range, not one number. A student is average when they're close to the class mean: within half the class's spread. Above it is "above", under it is "below". Examples below are from the demo table's first exam.
