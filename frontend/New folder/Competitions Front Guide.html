1 · must

Send the invite code at signup

The backend already accepts inviterCode on every signup endpoint. The site never reads it from the link and never sends it. In the test, a friend who signed up from A's link got no inviter, and A's count stayed 0.

What to build
  1. Read it on arrival. On /sign-up and /sign-in, if the URL has ?inviterCode=…, save it: sessionStorage.setItem("inviterCode", code). It must survive the move to /verify-phone, the profile form and Google's redirect.
  2. Show it. On the profile step of a new account, add an optional field كود الدعوة (اختياري), prefilled from storage, editable, dir="ltr". People who got the code by voice or chat type it here.
  3. Send it in the body of the request that creates the account (the three endpoints below). Send it as typed: the server trims it, uppercases it and drops spaces, - and _.
  4. Clear it from storage after the account is created.
  • An unknown code is ignored without an error: the signup still succeeds. Don't block signup on it.
  • It only counts for a brand-new account, or a guest finishing signup. Sending it on a sign-in to an existing account does nothing.
POST/api/auth/phone-complete-signupafter phone-verify says NeedsSignup

The phone path: phone-login-request → phone-verify (answers NeedsSignup: true for a new number) → this call, which creates the account.

Send
{
  "phoneNumber": "01012345678",
  "name": "عبدالله",
  "region": …,                // as the form sends it today
  "inviterCode": "7595148B"   // new: from storage or the field
}
Get
{ "message": "Account creation complete.",
  "token": { "token": "…", "refreshToken": "…", "expiresAt": "…" } }
POST/api/auth/googleGoogle, step 1
Send
{ "idToken": "<Google ID token>",
  "inviterCode": "7595148B" }   // new
Notes

For an existing Google account this signs in, and the code is ignored. For a new one the flow continues to google/phone-request; keep the code in storage for step 3.

POST/api/auth/google/phone-verifyGoogle, step 3: creates the account
Send
{ "idToken": "<same Google ID token>",
  "phoneNumber": "01012345678",
  "code": "123456",
  "inviterCode": "7595148B" }   // new
Notes

This is the call that links the inviter for Google signups. Step 2, google/phone-request, takes no code.

4 · should

Weekly points card

The نقاطك هذا الأسبوع face (gold league, #6 of 30, 1,755 points, the breakdown, a 7-day streak) is hard-coded in the page and calls no API. It also showed a 7-day streak to a student whose real streak was 1, and its text says every point comes from real study.

  • Hide the points face and the نقاطك هذا الأسبوع bar until there's an API for it, and keep the invite card open on its own.
  • Or keep it, with a قريبًا badge and the numbers blurred, so nobody reads them as theirs.
