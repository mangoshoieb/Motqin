Phone sign-up and sign-in

The same three calls serve sign-up and sign-in: a new number goes on to complete profile, an existing one is signed in after the code.

POST/api/auth/phone-complete-signupa verified new number · a guest token upgrades that guestchanged

Creates the account from complete profile («أكمل بياناتك»). changed Country, stage and grade are now required; the old Egypt · Secondary · 3rd default is gone. Sent with a guest's token, the guest's own row becomes the account and keeps its data.

Body fieldRulesMeaning
phoneNumberrequiredThe verified number.
namerequired · 3–100 · trimmedالاسم
countryrequired · newالدولة: a value from lookups/countries.
regionrequired when country is 1 (Egypt)المحافظة, 1–27. Ignored for other countries.
educationalStagerequired for students · new1 ابتدائي · 2 إعدادي · 3 ثانوي · 4 جامعي · 5 خريج. Not sent for teachers and parents.
gradeLevelrequired for students, not for 5 · newPrimary 1–6, Preparatory 1–3, Secondary 1–3, University 1–6.
inviterCodeoptionalA wrong code is refused.
accountTypeoptional · new"Student" (default), "Teacher", "Mentor". Teachers and parents are saved as خريج with gradeLevel 0.
Valid 
{ "phoneNumber": "+966500000123",
  "name": "TJ Abroad", "country": 2,
  "educationalStage": 3, "gradeLevel": 2 }

{ "phoneNumber": "01000000222",
  "name": "TJ Teacher Two", "country": 1,
  "region": 3, "accountType": "Teacher" }
200
{ "message": "Account creation complete.",
  "token": { "token": "…", "refreshToken": "…",
             "expiresAt": "…" } }

With a guest's token: the same, plus "guestDataDiscarded": false. A number that already has an account while a guest is signed in: "Signed in to your existing account." with "guestDataDiscarded": true.

Google

changed A new Google user fills in the «بياناتك» form first. A phone is then needed only for a Secondary student (ثانوي, any country), a teacher or a parent; any other student gets the account at once, with no phone.

POST/api/auth/googleanyone with a Google ID tokenchanged

Called twice for a new user: first by the Google button with only the token, then by «التالي» on the form with the form fields.

inviterCodeoptionalChecked for a new user.
fullName · country · region · educationalStage · gradeLevelnew second call onlyThe same rules as complete profile (fullName instead of name).
accountTypeoptional · new"Teacher" / "Mentor" from the sign-up page lines.
Valid · the four answers 
1 · Google button
{ "idToken": "…", "inviterCode": "7595148B" }

2 · «التالي» on the form
{ "idToken": "…", "inviterCode": "7595148B",
  "fullName": "محمد أحمد", "country": 1, "region": 2,
  "educationalStage": 1, "gradeLevel": 5 }
existing account → signed in
200 { "token": "…", "refreshToken": "…", "expiresAt": "…" }

  2. POST/api/auth/phone-login-request { "phoneNumber": "+966 50 000 0123", "inviterCode": "ZZZZ9999" }

  3. POST/api/auth/phone-verify with whatsApp.otp

    200 "needsSignup": true.
