Session Extra Minutes API

GET/api/study-session/additional-timeregistered user or guest

When to call: every time the planner or session screen opens or the page is refreshed. The server decides whether the timer should show. 200: show it, counting up from additionalSeconds, and hide it after secondsUntilIgnored seconds. 204: show nothing.

Request 
GET /api/study-session/additional-time
Authorization: Bearer {token}

No query, no body.

Good · 200: show the timer 
{
  "sessionId": 831,
  "endTime": "2026-11-07T17:18:18.0060109Z",
  "serverTimeUtc": "2026-11-07T17:18:18.9198998Z",
  "additionalSeconds": 0,
  "secondsUntilIgnored": 7199
}
FieldMeaning
sessionIdThe session the minutes belong to. Use it for add-time or ignore.
endTimeWhen that session ended (UTC). For a missed session: its planned end.
serverTimeUtcThe server's clock, to correct a device with a wrong time.
additionalSecondsSeconds since endTime. Start the timer from here.
secondsUntilIgnoredSeconds until the timer switches itself off, 2 hours after endTime.
Good · 204: show nothing (empty body)
  • A session is running, or a break is running.
  • The student never ended a session, or the latest one is a manually logged session.
  • The latest ended session's minutes were already added (add-time) or dismissed (ignore).
  • A break was started after the latest session.
  • 2 hours have passed since the latest session ended.
Bad
SendGet
No token, or an expired one401 empty body. Refresh the token and retry.
A server error400 { "success": false, "message": "An error occurred while loading the extra minutes." }. Show nothing.
PUT/api/study-session/{id}/ignore-additional-timeregistered user or guest

When to call: when the student says no to the extra minutes (closes the prompt or taps "don't add"). After it, the timer is never shown again for that session. To add the minutes instead, call PUT /api/study-session/{id}/add-time with { "minutesToAdd": n }: that turns the timer off too, and accepts at most the minutes that really passed.

Request 
PUT /api/study-session/831/ignore-additional-time
Authorization: Bearer {token}

{id} is sessionId from the GET. No body.
