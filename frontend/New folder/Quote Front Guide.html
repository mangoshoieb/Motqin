2 · should

Error toasts from the code

Error body (all quote endpoints)
// 400 / 403 / 404
{ "success": false,
  "data": null,
  "error": {
    "code": "comment_too_long",
    "message": "A comment can be at most 300 characters."
  } }
Do
onError: err => {
  const code = err?.response?.data?.error?.code;
  toast.error(errorCodeMessage(code) ?? "تعذر إتمام العملية، حاول مرة أخرى");
}

Add it to the mutations for adding a comment (box and reply), editing, deleting, and reacting. The reaction ones already roll back; add the toast after the rollback.

Live events

A new hub event at midnight, and a reply to a comment that was deleted meanwhile.

HUBReceiveNewDaynew · sent to everyone at 00:00 Cairo time
Payload
{ "date": "2026-11-15" }
Do
s.on("ReceiveNewDay", () => {
  n.invalidateQueries({ queryKey: ["quote", "today"] });
  n.invalidateQueries({ queryKey: ["quote", "educational-day"] });
});

The card only connects to the hub while it has a quote. On a day with no quote, refetch today's quote when the window regains focus so a quote scheduled later still appears.

POST/api/quotes/commentreply to a deleted comment

Handle a reply to a comment that was deleted (by an admin or its author) while the card was open: tell the student it's deleted.

Get · 400
{ "success": false, "data": null,
  "error": {
    "code": "parent_comment_deleted",
    "message": "This comment was deleted, so it can't be replied to."
  } }
Do (in the reply box)
onError: err => {
  if (err?.response?.data?.error?.code === "parent_comment_deleted") {
    toast.error(errorCodeMessage("parent_comment_deleted"));
    // "تم حذف هذا التعليق، لا يمكن الرد عليه"
    onDone();                                            // close the reply box
    qc.invalidateQueries({ queryKey: ["quote", "today"] }); // drop the deleted comment
  }
}
After deploying

Check

  1. As a 3rd-secondary student, the badge shows اليوم N من العام الدراسي and the days left. Network: /quotes/academic-day 200, no call to /admin/quotes/educational-day.
  2. As a student whose stage has no calendar (for example primary), no badge and no error.
  3. Paste a 301-character comment through the API or devtools: the card shows التعليق أطول من 300 حرف.
  4. Open the card in two tabs, delete a comment in one: the other tab shows it gone. Deleting it again from the stale tab shows التعليق غير موجود أو تم حذفه.
  5. Delete a comment that has replies: the dialog warns about the replies, the whole thread disappears, and the header drops by the thread's size.
  6. Leave the card open past midnight Cairo time: the quote and the badge change without a reload.
