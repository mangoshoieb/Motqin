Fix 2

One week start everywhere

changed responses

Now: the site's "next week" always starts on Sunday, while the server planned from the student's own week start (Saturday for everyone). On Wednesday 11 Nov the AI put tasks on Saturday 14, which the site treats as this week, so they were missing from the next-week board.

Build
  • The next-week board and the busy-times step follow startOfWeek from planner/basic. Or load the board with GET /api/study-plan/filter?Duration=NextWeek, which already uses it.
  • After plan-with-ai, show the week it planned from weekStart / weekEnd.
  • Preferences page: hide "عند عدم إنهاء مهمة" for now, and put a "بداية الأسبوع" choice in its place (Sunday … Saturday).

Every student's week start was set to Sunday (0) on 12 Nov, and Sunday is the default for new preferences.

Fix 4

AI planner step 3: goals

Now: a goal can be split across days (تقسيم المهام (عدد الأيام)) with a day and minutes per part, but the request has no day field, so the chosen days are lost, and the list shows totals that don't match the parts.

Build
  • Remove splitting a goal across days. One goal is one item in the request.
  • Rebuild the goals view as shown in the WhatsApp video about setting goals for the AI planner.
  • Check the minutes before sending: more than 0 and at most 720. Show an error on the goal and don't send until it's fixed.

The server no longer fails on bad minutes: a goal with 0 or less, or more than 720, is saved as 60 minutes. That is only a guard. The front's check is the real one.
