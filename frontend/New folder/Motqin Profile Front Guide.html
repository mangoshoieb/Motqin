PUT/api/users/meregistered user · guestnew

Edit the profile: the تعديل form and الوصف. Every field is optional; send only what changed: a field left out (or null) is kept, so it works like a partial update even though the verb is PUT. PATCH answers 405. Returns the whole updated profile, the same shape as GET /me.

Body fieldRulesMeaning
fullNameoptional · 1–100 · not only spacesالاسم, trimmed.
regionoptional · 1–27المحافظة. Can be changed, not cleared.
descriptionoptional · up to 500الوصف, trimmed. "" or spaces → removed (null).
educationalStageoptional · 1–5المرحلة التعليمية. new 5 = Graduate (خريج).
gradeLeveloptional · 1–6الصف الدراسي

Lookups and dependencies
GET /api/lookups/egyptian-governoratesfor the governorate dropdown.
  • Email, phone, country and photo are not in this endpoint; they have their own flows.
  • Changing stage or grade changes which subjects the app offers; reload subject lists after a save that changed them.

Edit only the guest's profile.

  1. No token
  2. Every /api/users endpoint with no Authorization header

    401, empty body, for GET / PUT /me.

  3. Guest profile
  4. GET/api/users/me

    200, "description": null.

  5. PUT/api/users/me { "description": " طالب في الثانوية العامة " }

    200, the text without the outer spaces; headers X-Guest-Reminder: save_your_data. GET /me shows it too.

  6. PUT {}, then { "fullName": "Profile Test", "region": 2, "educationalStage": 3, "gradeLevel": 2 }

    200 both; the first changes nothing, the second changes those four and keeps the description.

  7. PUT { "description": "" } · { "description": " " } · 500 characters

    200: null, null, then the 500 characters.

  8. Bad bodies
